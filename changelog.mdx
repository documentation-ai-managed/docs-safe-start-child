## Recent Updates

<Update label="2025-01-15" description="v1.2.0" tags={["feature", "improvement"]}>
## New Features

- Added custom-fit banister guards compliant with the latest ASTM F1004 standards for enhanced stair safety.
- Introduced eco-friendly, non-toxic latch options for cabinets and drawers, available in multiple finishes.

## Improvements

- Expanded service coverage to include remote consultations via video for initial home assessments.
- Optimized installation timelines, reducing average project completion by 20% through streamlined processes.

## Bug Fixes

- Resolved compatibility issues with certain modern door hardware for pressure-mounted gates.
</Update>

<Update label="2024-12-10" description="v1.1.0" tags={["feature", "bugfix"]}>
## New Features

- Launched new product line: adjustable window fall prevention screens with quick-release mechanisms.
- Integrated client feedback portal for post-installation surveys and ongoing support requests.

## Bug Fixes

- Fixed measurement inaccuracies in online gate configurator for non-standard openings.
- Updated compliance documentation to reflect CPSC guidelines on pool barrier installations.
</Update>

<Update label="2024-11-05" description="v1.0.0" tags={["feature", "breaking"]}>
## New Features

- Full rollout of premium hardware kits, including hardware-mount gates for high-traffic areas.
- Added toddler-height outlet covers and edge bumpers as standard in all safety packages.

## Breaking Changes

## Improvements

- Enhanced training for technicians on emerging safety standards from Safe Kids Worldwide.
